# 0.13.0：日常操作与界面细化

当前版本为 **0.13.0/code34**。本轮优先完善现有软件设计，沿用既有节点、备份、分流和检测能力，没有新增协议或网络服务。**真实 API 24 平板的安装与联网验收已按用户要求暂停，不能把兼容代码或界面预览记为平板联网通过。**

## 本轮变化

- **首页**：没有节点时主按钮直接进入添加；提供当前网络设置摘要和直达入口；宽屏左侧突出连接，右侧集中节点、网络设置和流量，减少重复品牌标题。
- **节点页**：宽屏采用紧凑信息行和稳定操作区，窄屏保持纵向布局和可换行操作；当前节点用底色与标识区分。批量按钮显示筛选数量，新增清空搜索与结果数；详细机制默认收进“检测说明”，仅本应用临时 VPN 提示仍可见。原菜单、连接期间限制和批量队列行为保留。
- **设置页**：入口分为“连接与数据”“帮助与说明”；外观三选项缩小占用，保留选中状态和无障碍说明，开发工具保持较低层级及预览版禁用。
- **编辑页**：新增未保存状态；没有改动时不执行保存，带改动返回时确认继续编辑或放弃。反馈固定在保存区，端口提供数字输入及 1–65535 行内校验。对话框迟到结果、重复返回和提交后的读回异常分别处理，不自动把草稿写入文件。

仍沿用 840 vp 表单上限、1024 vp 侧导航、680 vp 首页可用内容双栏规则。前一阶段的布局与限制见[阶段十二](phase12-adaptive-layout-verification.md)。

## API 24 兼容准备

最低兼容配置改为 **`6.1.1(24)`**，编译与目标 SDK 仍为 **`26.0.0`**。真实核心路径仍是 ARM64；x86_64 `-ui-preview` 包不含 VPN 转发核心。

VPN 授权观察器仅在系统 API 至少为 26 且工厂函数存在时创建；API 24 不调用该接口。没有同一 run 服务状态的启动请求在 25 秒后先写停止命令，再转为可重试失败；已有服务和其他 UI 所有者不由此回退处理。启动尝试使用 generation 和固定 run 标识隔离，旧 Promise 的成功、失败及 finally 不应改动新尝试。扩展保留 20 秒启动准入与命令校验，拒绝过期或已取消请求。

以上已由声明审计和合成测试覆盖，但不是 API 24 真机授权、启动、DNS/HTTPS 或资源清理的通过记录。真实鸿蒙 PC 也仍待验收；当前 x86_64 模拟器核心限制不能泛化为所有 ARM64 电脑的限制。
