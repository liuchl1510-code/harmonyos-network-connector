最终版本为 0.11.1/code31，初始候选为 0.11.0/code30。本轮修改 ArkTS 应用层、配置生成和验证脚本，C++ 桥接、Xray 26.6.1、Hev 2.9.0 及 Go 工具链保持原版本。

## 使用方法

设置 → 分流与 DNS：默认“全部代理”。选择“规则分流”后，可启用绕过局域网，或每行填写一个域名、IPv4 地址/CIDR 网段。普通域名（或 `domain:`）包含子域名，`full:` 仅匹配完整域名。IP 与域名分别生成规则，以实现“匹配其中任一项”。合计最多 300 条；不支持正则、IPv6、GeoIP/GeoSite 分类数据。

用户规则优先级为阻断、指定代理、指定直连、局域网，未命中时走当前节点。DNS 接管、IPv6 阻断和内部虚拟网段保护先于用户规则。域名匹配依据 HTTP/TLS 嗅探，`routeOnly` 保持原目标；不能识别域名的连接按 IP 规则或默认出站处理。局域网覆盖 RFC1918 和 IPv4 链路本地网段，未提供“绕过大陆”数据库或分应用配置。

DNS 接受域名或 IPv4 的 HTTPS URL，默认 `https://1.1.1.1/dns-query`。HTTPS DNS 始终经当前节点，URL 的域名交远端节点解析；不新增客户端系统 DNS 回退。Xray 使用 URL 主机名进行证书验证。节点服务器自己的域名仍按现有物理网络 IPv4 预解析策略处理。

网络设置须断开后保存，下一次普通连接生效。启动时深拷贝冻结策略，网络恢复沿用这一副本。节点检测和开发者短时验证继续使用默认全部代理/DNS 配置，避免用户直连规则造成误判。首页流量为代理出站计数，不包含直连流量。

节点 → 更多 → 编辑：提供当前协议的基本参数表单和完整单 outbound JSON。高级受支持字段在编辑往返中保留。切换协议或传输类型通过 JSON 编辑完成；仍受现有四种协议与 TCP/RAW、WS、gRPC 导入限制。保存检查节点库 revision，防止过期页面覆盖新数据；节点 ID、当前选择和订阅归属保留。

节点 → 更多 → 导出，或设置 → 节点备份与恢复：通过系统文件选择器保存单节点 JSON 或整个节点库。备份包含节点、订阅地址和当前选择，不含网络设置、外观、日志或检测历史，也不含额外应用层加密。文件包含凭据；应用仅在用户选择保存后写出。恢复先读取并验证最多 5 MiB 的 JSON，再显示数量和当前选择，明确确认后原子替换整个节点库；失败保留原文件，过期预览拒绝覆盖。

节点 → 检测筛选结果：固定当前所有搜索匹配项（包括未展开项，最多 500），逐个临时建立仅本应用的 VPN。观察到服务 PID 后，必须确认其退出才能开始下一项；清理确认不能替代进程退出。检查异常或后续 PID 缺失不会绕过等待。取消、离页、授权拒绝或会话/配置不匹配会停止后续队列。支持按成功 HTTPS 请求耗时排序显示，失败/未测项靠后；不修改节点库顺序或当前选择。检测不是下载带宽测速。
