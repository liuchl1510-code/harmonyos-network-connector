# 0.23.0：v2rayN 白名单与鸿蒙电脑实测

2026-09-23，新增“网络设置 → 进入 VPN 后的流量规则 → 白名单（绕过大陆）”。默认仍为全部代理；已有自定义规则、应用范围和 HTTPS DNS 设置保留。保存后下次连接生效，连接期间不能修改或保存分流设置。

## 规则来源与行为

采用 [v2rayN 7.24.9 的官方内置白名单](https://github.com/2dust/v2rayN/blob/521230c40d5c180bc0727cf4003907edfae5a3e0/v2rayN/ServiceLib/Sample/custom_routing_white)，固定提交 `521230c40d5c180bc0727cf4003907edfae5a3e0`。按原顺序匹配：UDP 443 阻断、Google 代理、私有 IP 与域名直连、上游指定的公共 DNS 地址与域名直连、中国 IP 与域名直连，其余代理。仅将出站标签映射到本应用的标签，并限定作用于连接入口；不会混入此前保存的自定义列表。

保留上游默认的 `AsIs` 路由策略。启用 HTTP/TLS 域名嗅探且仅用于路由，原目标 IP 也可参与匹配。与此前应用能力一致，接管的 DNS 仍经节点发给配置的 DoH，DNS 和虚拟接口保护规则优先，IPv6 仍被捕获后阻断。因此本次对齐的是内置白名单的 IPv4 分流，不声称复制了 v2rayN 的全部 DNS、IPv6 或用户自定义配置。

分类数据来自 Loyalsoldier `v2ray-rules-dat` 的固定 `202609222357` 发布。保留 `geoip:cn/private`、`geosite:cn/private/google` 分类的完整 protobuf 原字节，包括正则、完整域名和子域规则；仅省略无关分类，两个资源合计 2,133,911 字节。规则、源数据和提取后文件的大小、哈希、类别计数、署名、许可及复现命令见 [rules/README.md](../rules/README.md) 与 [sources.lock.json](../rules/sources.lock.json)。连接时不下载或自动更新数据库。

## 实现

- `NetworkPolicy` 增加独立 `whitelist` 模式；全局及原有自定义规则保持原行为，旧设置读取无需写回迁移。
- `ConnectionConfig` 为白名单提供直连／阻断出站及嗅探，保留代理兜底和现有 DNS、IPv6、虚拟地址保护。
- `RoutingAssets` 在启动 Xray 前校验打包数据的固定大小与 SHA-256；私有缓存逐字节读回核对，缺失或损坏时经临时文件、同步、读回和重命名替换。打包数据错误则中止启动，不降级为另一种分流模式。取消准备后不会继续加载核心。
- 沿用 libXray 已有的 `datDir` 接口，无需修改 C++、Go 适配或重编上游 Xray／Hev 库。
- 设置按钮使用整行布局，提供选择状态和大字号换行；关于及隐私说明补充规则来源和联网行为。

## 鸿蒙电脑实测

在上次同一台 API26、ARM64 `2in1` 电脑上，先重新采集并独立核对 12 个文件的当日基线，确认旧连接已完成清理，再保留数据升级。未沿用旧基线覆盖当前节点或服务状态。

| 真实会话 | 百度 HTTPS 请求的核心路由 | Cloudflare DNS／HTTPS |
| --- | --- | --- |
| 全局基线 | `nodeProxy` | 通过，路由为 `nodeProxy` |
| 白名单 | `direct`，浏览器成功显示本次 robots.txt 页面 | 通过，路由为 `nodeProxy` |
| 切回全局 | `nodeProxy` | 通过，路由为 `nodeProxy` |

每次浏览器请求带新的查询参数，路由证据取自该会话本次请求后的日志增量；全局不嗅探域名时，使用本次 DNS 回答与目标 IP 路由关联。白名单会话另行读回电脑私有目录中的两份数据库，与构建资源完全相同。三次连接的 socket 保护失败数均为零，正常断开后均核对同 runId／服务 PID 的清理回执，独立两次确认服务进程不存在。

设置页在普通窗口和 360 × 700 vp、两倍字号下检查，白名单文字完整位于按钮内，三个模式及保存可操作；连接期间三个模式和保存按钮均禁用。该项为实际控件几何及操作检查，不将它扩大为所有主题的像素视觉验收。

收尾恢复原来的全局模式、窗口位置和大小，并通过正常冷启动恢复进程字号。节点库、节点配置、检测结果、外观等原文件保持不变；网络设置经 UI 保存为与原先缺省行为相同的全局配置，连接日志及控制状态记录本轮真实操作。最后停留首页，VPN 已断开。
